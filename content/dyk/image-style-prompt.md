# "Did you know?" — the image style prompt

The style fragment for generating the explorers' "Did you know?" illustrations
with Nano Banana (Google's Gemini image model). Append it to a prompt describing
the scene; it fixes the look, not the content. Recorded 2026-10-20.

Where it came from: it was not written first and used. Gemini was asked to
describe the first illustration, Jansons's (`assets/dyk-images/`), as a reusable
prompt fragment; that picture's own prompt is lost. Karajan's was then generated
from this fragment, less the sound-effect text and the drifting notes.

> In a rich 3D-style cartoon with textured digital brushwork, warm golden stage
> lighting, and deep, atmospheric shadows. The character has highly expressive,
> caricatured features with visible skin-texturing and volumetric shading,
> reminiscent of modern animated feature films. Outlined with soft, dark-colored
> strokes, the illustration uses a warm and colorful palette with cinematic
> highlights, featuring hand-drawn playful sound effect text (e.g., "TOOT!",
> "HOOO!") and musical notes drifting through the air. The background has a soft,
> warm stage glow, theatrical spotlight beams, and slightly out-of-focus crowd
> elements for a natural sense of depth.
